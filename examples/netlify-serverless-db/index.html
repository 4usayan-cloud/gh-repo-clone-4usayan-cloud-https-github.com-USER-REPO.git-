About This Example

This demonstrates a Netlify serverless function that acts as a simple JSON database.


Features:

  • ✅ GET requests to read data from JSON file
  • ✅ POST requests to write data to JSON file
  • ✅ File system operations in serverless function
  • ✅ Simple JSON-based persistence
  • ✅ No database required

Note: This demo uses mock responses. In production, deploy to Netlify to use actual serverless functions.

Function Code

// functions/db.js
const fs = require('fs');
const path = require('path');

exports.handler = async (event) => {
  const dbPath = path.join(__dirname, 'data.json');
  
  if (event.httpMethod === 'GET') {
    const data = JSON.parse(fs.readFileSync(dbPath));
    return { statusCode: 200, body: JSON.stringify(data) };
  }
  
  if (event.httpMethod === 'POST') {
    fs.writeFileSync(dbPath, event.body);
    return { statusCode: 200, body: 'Updated' };
  }
};
