React Contact Form

Basic Version - Exact Specification

About This Demo

This is the ContactFormBasic component that exactly matches the specification. It demonstrates a minimal React form with async submission using the Fetch API.


Features:

  • Uses FormData with Object.fromEntries
  • Shows loading state while submitting
  • Displays success message on completion
  • No headers in fetch request (minimal)
  • HTML5 form validation (required, email type)
